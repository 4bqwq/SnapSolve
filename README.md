# SnapSolve

屏幕截图问答工具：按全局快捷键截取主屏，快路 VLM 和慢路 VLM+LLM 并发生成答案，并通过浏览器 SSE 页面实时显示。

## 使用

1. 安装依赖：

   ```powershell
   uv sync
   ```

2. 创建配置：

   ```powershell
   cp config.example.toml config.toml
   ```

3. 编辑 `config.toml`，分别填入 VLM 和 LLM 的 OpenAI 兼容 Chat Completions API 配置。

4. 启动：

   ```powershell
   uv run snapsolve
   ```

启动后服务会监听端口，手动打开 `http://127.0.0.1:8765/` 查看输出页面，也可以把浏览器放到副屏。快捷键必须在 `config.toml` 的 `[hotkey].sequence` 中配置，示例配置为 `Alt+V`；每次触发都会新建一个题目标签页，页面内可用左右方向键切换标签。

网页本身也支持同一个快捷键触发：只要浏览器焦点在 SnapSolve 页面上，按配置的快捷键会向服务端发送一次截图请求。局域网另一台电脑打开页面后也可以用这个快捷键触发答题电脑截图；同一台电脑上则由页面快捷键和本机全局热键共同覆盖，服务端会防抖，避免一次按键生成重复标签。页面顶部会显示当前快捷键，并提供一个小的“截图”按钮，点击后同样会触发截图。

## 局域网访问

默认启动只监听本机。如果答题电脑负责截图和按快捷键，另一台电脑只负责显示页面，可以用局域网模式启动：

```powershell
uv run snapsolve --lan
```

`--lan` 会监听 `0.0.0.0`，启动日志会打印本机和局域网访问地址，例如：

```text
SnapSolve access URLs:
  Local: http://127.0.0.1:8765/
  LAN:   http://192.168.1.23:8765/
```

在另一台同局域网电脑的浏览器里打开 `LAN` 地址即可。页面顶部也会显示当前可用的局域网地址，方便确认连接目标。

如果另一台电脑打不开页面，先确认两台电脑在同一局域网内，并检查 Windows 防火墙是否允许当前 Python/uvicorn 进程监听该端口。

也可以临时覆盖监听地址或端口：

```powershell
uv run snapsolve --host 0.0.0.0 --port 9000
```

## 性格测试

每次截图后，服务会先用 VLM 对图片做一次轻量题型判断，只判断是否为性格测试、人格测评、职业性格问卷或同意程度量表。判定为普通题目时，快路和慢路的行为保持不变。

判定为性格测试时，快路和慢路会切换到通用的理想职场执行型性格画像：严于律己、团队合作、守时守信、谨慎细致、低调稳定、计划性强、不贪功。性格测试题使用独立上下文历史，保证同一次服务启动期间前后回答保持统一。

## 上下文

快路 VLM 和慢路 LLM 分别维护独立上下文。上下文只保存在当前服务进程内存中：每次启动服务器后从空上下文开始累计；按 `Ctrl+C` 关闭后上下文直接丢弃，重新启动不会继承上次提问历史。

## 配置要点

- `[server]`：服务监听地址和端口。
- `[hotkey].sequence`：必填，本机全局热键和网页焦点热键共用这一项，例如 `Alt+V`。
- `[vlm_api]`：快路回答和截图文字提取使用的视觉模型 API。
- `[llm_api]`：慢路深度推理使用的文本模型 API。

## 接口

- `GET /`：输出页面
- `GET /events`：SSE 事件流
- `POST /capture`：手动或网页快捷键触发一次截图
- `GET /health`：健康检查
- `GET /info`：当前本机和局域网访问地址
